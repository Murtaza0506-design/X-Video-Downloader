# EB Garamond

Static instances cut from the variable fonts in
https://github.com/google/fonts/tree/main/ofl/ebgaramond, at weights 400, 500
and 600, upright and italic, with `fontTools.varLib.instancer`. They live here
so the book can be rebuilt without a network.

Licensed under the SIL Open Font License 1.1; the licence is in `OFL.txt` and
travels with the files. The subsets embedded in the PDFs are covered by the
same licence, which permits embedding.
