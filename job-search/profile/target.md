# Target profile

What we are actually aiming at. Written down because an unwritten target
quietly becomes "any job", and an unfocused search reads as unfocused on
every application it produces.

| Field | Value |
| --- | --- |
| Role family | **Project support** — project support officer, project coordinator, project administrator, PMO analyst. Entry route into delivery, not a PM title yet. |
| Level | Entry to delivery; not junior in general — the CV already has project work on it |
| Development plan | PRINCE2 or agile certification alongside the role; a role that funds or supports it is worth more than a slightly better-paid one that doesn't |
| Employment type | **Permanent** |
| Work mode | **No strong preference** — remote, hybrid or onsite all in scope |
| Sector preference | _open — to be narrowed once the CV shows where the domain knowledge already is_ |
| Location | _needed_ |
| Work authorisation | _needed — country, and whether sponsorship is required_ |
| Salary floor | _needed — the number below which you say no_ |
| Notice / availability | _needed_ |
| Dealbreakers | _needed_ |

## Position

Project work on the CV, no project management title. This is the strongest
of the three starting positions for a pivot: the evidence exists and needs
renaming and quantifying rather than inventing. The whole search turns on
finding it, which is what the CV read is for.

## Transferable story

_The one-paragraph answer to "so why project management?" — built from what
is already on the CV, not from enthusiasm. Written once here, then reused
across every application so the story stays consistent. Blocked on the CV._
