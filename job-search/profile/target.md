# Target profile

What we are actually aiming at. Written down because an unwritten target
quietly becomes "any job", and an unfocused search reads as unfocused on
every application it produces.

> **Not yet filled in.** Needs answering before sourcing starts.

| Field | Value |
| --- | --- |
| Role family | _project / programme / delivery / PMO / TPM — see `reference/pm-role-map.md`_ |
| Level | _coordinator, PM, senior PM, programme manager_ |
| Sector preference | _e.g. construction, financial services, public sector, SaaS, healthcare_ |
| Location | _city, and how far you'd commute_ |
| Remote / hybrid / onsite | _and how firm that is_ |
| Work authorisation | _country, and whether sponsorship is needed_ |
| Employment type | _permanent, contract, interim, open_ |
| Salary floor | _the number below which you say no_ |
| Salary target | _the number worth stretching for_ |
| Notice / availability | _immediate?_ |
| Dealbreakers | _travel, on-call, shift work, sectors you won't work in_ |
| Timeline pressure | _how long the search can run before the answer changes_ |

## Transferable story

_The one-paragraph answer to "so why project management?" — built from what
