# Language style guide

Standing rules for all newsletter content, current and future. Check new
text against these before publishing an issue.

1. **Allah, not God.** Use "Allah" throughout, including inside English
   translations of sayings, ayahs, and hadith. This is a translation
   choice for this publication, not a change to what anyone actually
   said (in Arabic it was always "Allah").

2. **Never "conquered" for Makkah.** When writing about the Prophet's ﷺ
   return to Makkah, don't use "conquered" or "conquest." Use "reclaimed"
   or similar (e.g. "the reclaiming of Makkah," "Makkah was reclaimed").
   This has come up as a planned topic for a future "From the History"
   entry, not yet written, so there's nothing to fix in issue 1, but
   watch for it.
